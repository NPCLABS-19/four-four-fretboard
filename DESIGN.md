# 4/4 approved refinement

Desktop-first interactive portfolio, using the A24 reference's tactile photographic discs and negative space. Astro, TypeScript and GSAP maintain one clock; Web Audio supplies muted electric notes, chorus and a warm chord-following drone.

The original supplied 4/4 logo is restored. Typography uses Helvetica throughout. Night is the default, with a day palette toggle. The guitar voicings on D/G/B/E strings remain Gmaj7 [5,4,3,2], Amaj7 [7,6,5,4] and Fmaj7 [3,2,1,0]. Each chord represents one project and uses only that project's supplied images. Other discs are exactly 30% smaller than the main disc. Chapter spacing and maximum dimensions preserve clearance during motion and hover.

Project typography fades in on hover and keyboard focus, then fades out when leaving. NBA uses upper-left stacked type and a lower-right service block; Red Bull uses an inset horizontal title and a narrow lower-right service block; Suede Sounds uses lower-right stacked type and upper-left services. Headings describe the work: end-to-end production, experience design and production, space design and curation. Service headings are 22–36px on desktop, with 13–16px supporting copy. The canvas retains generous negative space.

Zoom out, the score view and the experimental text metronome have been removed following feedback. Sound defaults to on; browser autoplay restrictions may require the first click. The visible Sound control allows muting. At rest the instrument remains quiet visually; its motion comes from interaction. Reduced motion bypasses the two-second arrangement and perspective movements.

NBA House has a full-screen case study; other breakdowns remain clearly labelled previews. The user approved publication of this revision to NPCLABS-19 / GitHub Pages. About and Index retain their hover animation and do not open panels.
